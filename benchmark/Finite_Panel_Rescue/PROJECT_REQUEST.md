# 共享隐含技术批次、选择富集与有限克隆救援实验

请独立实现可迁移解算器，完成全部数值、科学解释与图表。输入为精确合成的重复技术测量期望，不是一次随机采样的频数，也不是需要估计的置信区间。只读取当前任务目录和明确传入的输入，不访问其他模型任务空间、组织者私有文件或历史答案，不联网搜索本题答案。

每层有已知数量panel_size个不同克隆成员。成员具有固定二元潜在反应U=(Y0,YA,YB,YAB,YR)，Y0是对照。未知的是各层32种类型的非负整数计数n_s(u)，层内和为N_s；q_s(u)=n_s(u)/N_s。克隆等分样本共享其所属成员的U，动作读取对应反应，不改变U。生物潜在反应不假设独立。每次完整观测或救援实验按层内已知先验抽取一次未观测技术批次B，整个实验保持同一B，包含所有成员、克隆等分、动作及缺失分支。B在入组前独立于成员U。只有给定层、成员U和同一个B后，各次技术读数的噪声才独立。给定U但边际化B后，读数通常相关。B不属于自然的对抗选择，也不能在每次读数或每个槽位重新抽取。

所有观测均给定成功进入指定cohort。整数面板须同时满足层内计数和、支持集、全部单项/同成员成对观测及observed_distinct.tsv的双成员条件读数期望包络。跨层记录先合并按share加权的入组分子与分母再条件化。支持限制是给定假设，不能写成已经证明自然因果。capture表有未用于三种观测文件的cohort时，不能声称对应观测记录已存在。

本版新增两种必须区分的成对观测：observed_pairs.tsv仍为同一成员的两份克隆等分；observed_distinct.tsv为先选层、均匀有序无放回抽两个不同成员，槽位0尝试进入cohort1、槽位1尝试进入cohort2，在**两者都成功入组**条件下的成对技术读数期望。给定层、两成员类型及同一个B，两次入组相互独立；各槽位入组概率由batch_capture表给定，两槽位可以使用不同cohort。区间[probability_lower,probability_upper]是已校准仪器给出的确定性期望包络，不是置信区间，不可当成某个点概率。完整整数面板必须使所有双成员条件概率都在包络内。总体记录先合并按原始share加权的两成员分子和共同分母，再取比率。

新增观测的富集只约束未知面板，不改变后续救援实验的采样：H/R/C仍按原始share、层内原始批次先验和均匀无放回两成员抽样计算，不把cohort富集后的权重套给救援实验。

连续外松弛的精确定义：对每层引入q_s(u)≥0且sum q=1，并引入任意非负对称有序类型对概率M_s(u,v)=M_s(v,u)，每一行之和等于q_s(u)（故两槽位边际都为q）。支持限制施于q；原有单项与同成员成对观测仍按q条件化，新增双成员观测按M条件化并满足原区间包络。这个比较集合**同时放松整数计数网格与有限面板二次抽样关系**；不要求M=q*q，也不强加某个有限计数n的无放回公式。物理整数面板的真实无放回M是其特例，因此这是外松弛。报告的relaxed界在这个明确集合内为锐界，但不一定能被物理整数面板达到。不能仅放松q却忽略新增观测，也不能把独立有放回乘积当作外松弛定义。

本版共享批次的联合观测定义：记p_s(b)为原始先验，c(c,s,u,b)为批次条件入组概率，l(a,s,U,y,b)为批次条件读数概率。channels.tsv与capture.tsv仅分别给出各自对原始B先验求平均的边际诊断，不能把两个边际相乘替代下述联合量。

- 单项观测：对同一个b求和，分子为sum_s,u,b alpha_s q_s(u) p_s(b)c(c,s,u,b)l(a,s,U,y,b)，分母删去l。
- 同成员克隆对：分子把上述l替换为l1(b)l2(b)，分母仍只含一次入组c。
- 两不同成员观测：分子为sum_s,u,v,b alpha_s M_s(u,v)p_s(b)c1(u,b)c2(v,b)l1(u,b)l2(v,b)，分母删去两项l。整数主问题M取真实无放回计数公式，连续比较M取前述对称耦合。

成功入组会同时改变类型与B的条件分布。双成员共同入组给定同一个B才独立，边际化B后不能用平均入组概率的乘积。不要先把B平均掉再相乘读数通道；不要把给定成功入组后的B后验用于未来未经该cohort筛选的目标实验。查询仍是同成员生物事件，类型反应不会被B改变。

救援路径的联合读数概率是sum_b p_s(b) product_steps l_step(b)。可直接对B枚举后积分全路径，或正确更新B后验；每一步均使用未更新先验重新平均是另一个实验。reset_batch诊断仅把每步读数通道换成channels.tsv边际，并在其自身产生的路径分布下积分H/R/C；保留原x、原整数可行面板集合、无放回成员抽样与所有生物事件定义，不重新拟合观测、不重新优化x。

任务分三部分：

1. 对queries中的同成员条件事件，在全部可行整数面板上求锐界和分母区间，并报告可达条件值数量。只在正分母面板上定义比率；分母上界不超过1e-10记undefined，两端NA，可达值数0；其余区间宽度不超过1e-7记identified，否则not_identified。分母下界0而上界正仍有定义。连续区间内部不必全可达。同时按前述定义的连续q与对称成员对耦合M外松弛，保留全部观测约束，报告相同查询在该外松弛集合上的锐界与分母区间。放松结果是比较，不是可行物理面板见证。
2. 审查全部给定完整协议树，只在合法的给定候选集内计算指标，不自行增加协议。一个实验先按share选一个层，再均匀无放回为槽位0与1预分配两个不同成员；随后按已公布x独立抽取协议，产生技术读数并沿树执行。x不依赖已抽成员类型或读数。树节点指定unit及action。每条结构路径最多四次测试，禁止重复同一(unit,action)，允许同一动作在不同槽位使用。每条路径的成本都必须不超过budget，缺失读数也花费动作成本。
3. 在全部合法协议上求两个全局最优随机组合：unconstrained不加伤害上限，robust同时要求组合最坏总体事件伤害不超过harm_limit，并满足每层conditional_harm_limit的条件成员伤害率限制。所有层共用同一组x，不能针对层另选组合。组合x公布后，自然选择一个完整可行整数面板配置（所有层的计数），它可知x，但不能按抽到的协议、成员、读数分支重新选面板。物理面板固定，成员抽样、协议随机、原始批次先验与条件技术噪声均取期望；自然不能选择B，不能依据B重选面板。风险限制作用于总体组合，不逐协议预筛。

对固定协议和整数面板，积分层、两名成员的有序无放回抽样、一次共享B及该B下全部噪声路径：

- H：至少一个槽位的Y0=0，并且同一槽位路径上实际测试了至少两种不同非对照干预且其真实反应为1。两个槽位各一个阳性不能凑成确认。对照不计救援路线，读数阳性不等于真实成功。
- R：至少一个槽位Y0=1，并且该槽位实际测试过至少一种真实反应为0的非对照干预。
- C：路径实际总成本的期望；U=H-cost_penalty*C。H是此实验的确认指标，不是临床疗效证明。

本版增加分层成员条件伤害，必须区别于上面“至少一名伤害”的事件概率R。对指定层s、完整面板n和协议路径，令E_s的路径值为已实际测试过至少一种非对照干预、且Y0=1的**成员人数**；令J_s的路径值为这些成员中，至少一种已测非对照干预真实反应为0的**受伤成员人数**。每个成员无论测试几种干预均最多计一次，两个槽位合计0、1或2。分别对该层内部的成员抽样与噪声取期望（不乘原始share），得到E_s(n,pi)、J_s(n,pi)。它们是人数期望，可能大于1；J_s≤E_s。总体R仍是至少一名受伤的实验事件概率，不等于J_s的人数期望。

组合x在层s、面板n上的条件成员伤害率定义为 J_s(n,x)/E_s(n,x)，其中J_s(n,x)=sum_pi x_pi J_s(n,pi)，E_s同理。这是重复实验中全部已暴露基线阳性成员的伤害比例，即先汇总人数再取比率；不能平均每个协议自己的比率，也不能把E_s换成“至少一名暴露”的事件概率。只在E_s>1e-10的面板上报告比率；若E_s上界≤1e-10则该层统计量undefined、端点NA，约束在没有此类暴露时为空约束，不能据此声称条件伤害率为0或临床安全。

robust对每个完整可行n、每个层s要求 J_s(n,x)-kappa_s*E_s(n,x)≤0，kappa_s来自strata.tsv的conditional_harm_limit；另保留总体max_n R_x(n)≤harm_limit。unconstrained忽略两类风险上限，但保留全部协议合法性限制。STOP的E、J、R都为0：它能降低总体事件伤害，但把一个固定危险协议与STOP混合时，正分母上的J/E不变，因此不能仅靠“不做实验”稀释条件伤害率。不同有暴露协议可以组合，但必须按共同面板上的总J/总E检查，而非逐协议预筛。

组合效用为min_n sum_pi x_pi U_pi(n)，最坏伤害为max_n sum_pi x_pi R_pi(n)。概率非负且和1；两个问题都保留全部路径合法性限制。报告最佳纯协议全部并列集合，以及混合最优。输出最坏值达到的整数面板，另给能证明全局上界的自然证书权重：证书允许混合多个可行整数面板，其平均计数不必为整数，不能冒充一个真实物理面板。证书与最优x允许不唯一，评分验证可行性和达到值，不逐元素复制参考向量。

额外诊断必须对自己所交的相同x重算：允许按协议身份各选最坏面板的比较值、minH-lambda*maxC拼接值、错误使用有放回独立抽样的最坏效用、错误把跨槽位救援阳性路线合并的最坏效用，以及错误在每次读数前独立重抽B的最坏效用reset_batch_worst_utility。详见RESULT_FORMAT.md；这些错误模型仅用作比较，不用于选择真正最优x。有些实例或最优x差异恰为0，须照实报告。
