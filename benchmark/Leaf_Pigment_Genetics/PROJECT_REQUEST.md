# 叶片淡色性状：候选位点的序列与遗传证据复核

## 背景与目标

我们整理了一批二倍体模式植物材料的叶片色素测量记录、候选基因组区段、CDS 注释和群体变异调用结果。部分材料叶色偏浅。研究组希望在不开展新实验的前提下，评估现有遗传数据最支持哪个候选位点、哪些变异具备可信的功能后果，以及这一判断能达到什么证据层级。

请独立选择分析步骤并完成结果。优先保证生物学推断和数据处理正确，图形简洁、可读即可。不需要下载数据库或建立复杂机器学习模型。不要根据基因的功能描述直接选择候选位点；要让序列、质量和材料间遗传证据共同决定结论。

## 提供的数据

`data/` 中包含：

- `draft_reference.fa`：候选区段参考 DNA 序列，多个 scaffold。
- `genes.gff3`：基因、转录本和 CDS 注释。
- `gene_catalog.tsv`：各基因的功能注释及转录本使用情况。
- `cohort_variants.vcf`：各材料的 VCF 变异及基因型。
- `phenotypes.tsv`：叶片色素指数和叶色表型记录。

这些是内部整理的精简候选区段资料，不能视作完整基因组筛查或功能实验结果。分析应以文件本身为准。

## 交付内容

请提供一份可重运行的独立分析程序，完成以下工作：

- 对 VCF 变异及质量记录进行核对，保留明确的质控结论。
- 结合 FASTA 与 GFF3，整理各变异在相关转录本上的预测功能后果。
- 综合每份材料的基因型和叶色测量，评价各候选基因的遗传证据。
- 给出最值得进一步功能验证的基因、关联变异和推断边界。
- 附一幅展示主要遗传证据的图和简短结论说明。

研究团队使用固定的数据集成系统，最终结果请**严格使用 `RESULT_FORMAT.md` 定义的表格列名和 JSON 字段**。所有数字必须由代码计算，不接受手工填写的固定答案。

程序须提供 `run.sh`，接受两个位置参数：

```bash
bash run.sh /path/to/data /path/to/output
```

运行时自动识别输入目录、全部材料 ID、基因 ID、转录本 ID 和变异 ID。不要在代码中写死这些值。允许使用 R、Python 或两者组合，所有输出均写到第二个参数对应的目录。完成前请自行检查能否从原始数据重新得到输出文件。
