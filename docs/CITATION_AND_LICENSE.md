# Citation, authorship, and licensing checklist

The materials are **prepared for GitHub publication**, but the repository owner
should make explicit choices about the following fields before releasing them.

## Suggested bibliographic citation (replace placeholders)

> **[Author name(s)]. (2026).** *BIPT v1.0: Bioinformatics Pelican Test —
> an author-led, synthetic plant-genetics evaluation of AI bioinformatics agents*
> (Version 1.0) [Software and dataset]. GitHub.
> `https://github.com/[USERNAME]/[REPOSITORY]`

No DOI is claimed. If a Zenodo archival release is later created, substitute
its real DOI only after registration succeeds.

## License

**No license is granted by default in this package.** Select a license before
publication based on the intended reuse:

- Original code: one conventional permissive option is **MIT**.
- Original text and figures: one conventional scholarly option is **CC BY 4.0**.
- Consider compatible terms for all third-party snippets (this release largely
  links to upstream repositories rather than copying their software).
- Avoid implicitly relicensing complete model-generated source archives that
  are **not included** here.

Adding a license is a **rights decision by the repository author**; public
visibility on GitHub is not equivalent to freely licensed reuse.

## Suggested GitHub description

> BIPT v1.0 — An independent 100-point, code-executed bioinformatics AI stress
> test using synthetic plant genetics. Methodology, data, and results for 11
> submitted configurations; scores reflect the author's views only.

Suggested topics: `bioinformatics`, `ai-benchmark`, `genomics`, `variant-annotation`,
`vcf`, `gff3`, `reproducibility`, `llm-agents`, `scientific-reasoning`.

## Author-only-views requirement

Include this explicit statement in every article, GitHub README, or repost:

**“The results, rankings, and interpretations presented here reflect only
the author's views and do not represent the official opinions or endorsements
of the AI model providers or any other organization.”**
