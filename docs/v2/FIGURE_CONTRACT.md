# Comparison figure contract

Core question: where do the observed single-run WorkBuddy configurations differ in frozen-task correctness, scientific reporting, hidden-case transfer and resource use?

Archetype: quantitative grid with a dominant score-decomposition panel. No winner is assumed before scoring.

Backend: R/ggplot2 plus base grid, editable base-R PDF, svglite SVG and ragg 600-dpi PNG. A working Cairo PDF device is an optional export route. White background, stable provider colors, explicit development and resumed-generation symbols. Planned final size about 183 mm wide; text floor 5 pt, direct model labels, source CSV and figure-generation script supplied.

Panel map: (a) total score decomposed into 60 numerical, 35 scientific and 5 delivery points; (b) released/held-out case scores with exit/delivery labels; (c) within-provider configuration differences using the same cases; (d) observed credits versus total score with elapsed time labels; (e–f) actual credits and elapsed minutes for all finalized service outcomes, separating initial and neutral-continuation phases. Panels are split across three figures for readability. Every original and resumed settled segment is included in total model cost.

Replicate unit: one original generation per listed configuration; five externally interrupted tasks are completed with disclosed neutral continuation messages in the same chat and directory. These are not independent new generations. The Flash row is a development/calibration baseline; mark it distinctly. The three cases are fixed heterogeneous scenarios, not random replicates. No statistical test, error bar or confidence interval; repeat execution is not independent generation. No synthetic placeholder observations.

Integrity: every plotted value comes from finalized original-submission scores and actual service bills. All eight configurations must have normal service completion and a final frozen score before export. Historical capped outcomes remain preserved separately. Operator aborts are documented in accounting, not ranked as zero ability. Keep v1.0 figures/data unchanged and separate.
