# 约 400 字读懂 BIPT v2.0

BIPT v2.0 可以理解成一场给 AI 的生信推理考试。它用合成数据，让模型根据检测线索判断：哪些结论能确定，哪些只能给范围，哪些无法判断，再选择满足题目风险限制的实验方案。难点是样本之间、重复检测之间和检测批次之间并不总能当作独立。模型既要算对，也要讲清证据，不能把相关性说成因果。

使用时，先下载“参测包”，给每个模型新建一个空文件夹，只把参测包解压进去。在 WorkBuddy 选择目录和模型，把包内 PARTICIPANT_PROMPT.txt 全文复制发送，完成后保存整个原始项目，记录型号、用时和积分，不替它修答案，也不把评分材料交给它。

评分时，所有模型的产物必须交给同一个固定评分模型，配合相同的评分程序和隐藏题。每套题满分100分：数值60分、科学解释35分、运行与交付5分；科学解释有明确错误，该项不得分。最终按公开题20%、两套隐藏题各40%合成。公开包可以直接试跑，完整正式评分还需组织者的私有评分包。分数只说明本题表现，不代表所有生信任务的能力。
